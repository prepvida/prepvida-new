Security

Data isolation

Every table in our database uses Row Level Security — a student can only ever query their own records, enforced at the database level, not just in the app.

Payment security

We never see or store your card details. Payments are handled entirely by Instamojo, and we verify payment success server-side before granting plan access.

Authentication

Login is handled through an encrypted authentication system with secure password storage and session tokens.

Reporting a security issue

If you discover a vulnerability, please report it responsibly to hello@prepvida.in rather than disclosing it publicly. We'll respond as quickly as we can.
